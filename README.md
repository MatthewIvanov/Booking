🏨 Hotel Booking System
📖 Описание
Проект Hotel Booking System — это веб-приложение, позволяющее пользователям бронировать номера в отелях, управлять бронированиями и получать информацию о доступных номерах. Система разработана с использованием современных технологий и обеспечивает простой и удобный интерфейс.

🌟 Функционал
Просмотр доступных номеров и информации об отелях.
Бронирование номеров.
Управление существующими бронированиями.
Авторизация и регистрация пользователей.
Панель администратора для управления номерами и бронированиями.

🚀 Установка и запуск
Предварительные требования
Установите Docker и Docker Compose.
Убедитесь, что на вашей машине установлен Python 3.8+ (если без Docker).
Инструкция
Клонируйте репозиторий:

bash
Копировать код
git clone <URL вашего репозитория>
cd <имя_проекта>
Создайте файл .env: Пример .env:

plaintext
Копировать код
DATABASE_URL=postgresql://user:password@db:5432/hotel_booking
SECRET_KEY=your_secret_key
DEBUG=True
Запустите проект с помощью Docker:

bash
Копировать код
docker-compose up --build
Доступ к приложению:

API: http://localhost:8000
Документация Swagger (если используется FastAPI): http://localhost:8000/docs
🔗 Эндпоинты API
Пользователи
POST /api/register/ — Регистрация нового пользователя.
POST /api/login/ — Авторизация пользователя.
GET /api/profile/ — Просмотр профиля пользователя.
Номера
GET /api/rooms/ — Список доступных номеров.
GET /api/rooms/{id}/ — Подробная информация о номере.
Бронирования
POST /api/bookings/ — Создать новое бронирование.
GET /api/bookings/ — Просмотр всех бронирований пользователя.
DELETE /api/bookings/{id}/ — Отмена бронирования.
